\begin{ProjectSummary}
Course project for EE 475 at Boğaziçi University. A blind deblurring pipeline that estimates the
blur kernel by multi-scale kernel estimation, learns a sparse dictionary from patches of clear
images with online dictionary learning, and recovers the sharp image with an ADMM-based
optimization, compared against a Wiener-filter baseline.
\end{ProjectSummary}
